# Compass-Clock

A beautiful analog clock built with HTML, CSS, and JavaScript, featuring a compass-like design.

## Description

This project is an interactive analog clock that displays the current time with a unique compass-inspired visual style. It uses SVG for the clock face and JavaScript to update the hands in real-time.

## Features

- Real-time analog clock
- Compass-style design with concentric circles for seconds, minutes, and hours
- Smooth animations for clock hands
- Responsive design

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/BinaryVortex/Compass-Clock.git
   ```

2. Open `index.html` in your web browser.

No additional dependencies or build steps are required.

## Project Structure

- `index.html`: Main HTML file containing the SVG clock structure.
- `style.css`: CSS styles for the clock appearance.
- `script.js`: JavaScript code for updating the clock hands.
